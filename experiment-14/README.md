# Experiment 14: Fork and Pull Request Workflow

## Steps performed
1. Forked [octocat/Spoon-Knife](https://github.com/octocat/Spoon-Knife) to [tharuncoder676/Spoon-Knife](https://github.com/tharuncoder676/Spoon-Knife)
2. Cloned the fork locally
3. Created a new branch `add-fork-counter-feature`
4. Added a "Pet the Octocat" click-counter feature (`index.html`, `script.js`)
5. Committed and pushed the branch
6. Opened Pull Request [#1](https://github.com/tharuncoder676/Spoon-Knife/pull/1)
7. Reviewed the PR and left feedback (counter should persist across reloads)
8. Pushed a follow-up commit addressing the feedback (persisted the count with `localStorage`)
9. Merged the Pull Request into `main`
